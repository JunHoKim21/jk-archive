# 개요 (Overview)

개인 프로젝트로 시작한 'SAGA AI Thumbnail Studio'의 1차 MVP(최소 기능 제품) 버전을 배포하며, 지금까지 구현한 핵심 기술들을 되돌아보고 앞으로의 고도화 방향(To-Do List)을 정리하는 회고록입니다. 

# 등장 배경 및 필요성 (Why)

새로운 아이디어를 빠르게 코드로 옮기다 보면, 기능이 누적될수록 "우리가 지금까지 뭘 만들었고, 앞으로 뭐가 더 필요한가?"에 대한 정리가 필수적입니다. 특히 FFmpeg 미디어 처리와 AI API 통신이 엮이면서 아키텍처가 복잡해졌기에, 기술 부채를 예방하고 다음 마일스톤을 명확히 하기 위해 현황을 문서화했습니다.

# 동작 원리 및 내부 구조 (현재까지의 성과)

현재 SAGA AI Studio는 아래와 같은 강력한 코어 기능들을 성공적으로 구동하고 있습니다.

1. 대용량 미디어 전처리 (FFmpeg)
   100MB가 넘는 원본 영상을 AI에 그대로 던지는 대신, Spring Boot 백엔드에서 FFmpeg를 구동해 오디오(MP3)만 30MB 수준으로 빠르게 추출합니다.
2. 멀티모달 AI 분석 (Gemini 1.5 Flash)
   추출된 오디오를 듣고 문맥을 파악해, 가장 매력적인 썸네일 구간(Timestamp)과 하이라이트 영상 구간(15~30초)을 찾아내며 적절한 카피를 뽑아냅니다.
3. 텍스트 동적 배치 (Dynamic Positioning)
   AI가 영상의 인물 구도까지 판단해 최적의 글씨 위치(`top-right`, `bottom-left` 등)를 추천해주면, FFmpeg가 이를 받아 사람 얼굴을 피해서 자막을 찰떡같이 합성합니다.
4. 인프라 무중단 배포 (Render & Docker)
   FFmpeg 의존성을 해결하기 위해 서버를 Docker로 패키징하고, 무료 클라우드(Render) 환경에 무사히 배포했습니다.

# 실무 코드 예제 (앞으로의 과제: To-Do List)

핵심 가치 검증은 끝났으므로, 이제는 사용자 경험(UX)과 인프라 안정성을 상용 서비스 수준으로 끌어올릴 차례입니다.
🎨 1. 사용자 경험(UX) 극대화
* 결과물 재생성 (Regenerate): 생성된 텍스트나 구도가 마음에 들지 않을 때 한 번 더 AI를 호출하는 기능.
* 디테일한 로딩 바: 단순히 빙글빙글 도는 로딩이 아니라 "오디오 추출 중 ➔ AI 분석 중 ➔ 자막 렌더링 중"으로 단계별 상태 표시.
* 커스텀 설정 UI: 폰트 종류, 텍스트 색상, 브랜드 태그를 사용자가 커스텀하는 패널 도입.
⚡️ 2. 핵심 기능 고도화
* 영상 자막(SRT) 자동 생성: 하이라이트 쇼츠 하단에 릴스/틱톡 스타일의 동적 자막 달기.
* 멀티 썸네일 제안: AI가 어그로형/정보전달형/감성형 3가지 썸네일 버전을 동시 제안.
🛠 3. 백엔드 인프라 최적화
* 찌꺼기 파일 청소: 서버 용량이 꽉 차지 않도록 매일 새벽 `/tmp` 폴더의 임시 영상을 지우는 Cron 스케줄러 개발.
* 토큰 매니징: 무료 API 일일 할당량(20회) 한계를 넘기 위한 API 키 로테이션 및 예외 처리 고도화.

# 한 줄 요약 (Summary)

대용량 미디어 경량화와 동적 AI 렌더링이라는 핵심 코어는 완벽히 구축되었습니다. 이제 디테일한 UX 개선과 엣지 케이스 방어를 통해 진정한 "나만의 썸네일 공장"으로 고도화할 예정입니다.

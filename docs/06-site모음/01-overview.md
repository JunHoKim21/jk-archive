## 📂 카테고리별 상세 안내

### 1. AI 서비스 & 최신 연구 실험실

#### 1) [Claude (Anthropic)](https://claude.ai)
* **특징**: 복잡한 아키텍처 분석, 긴 코드베이스 컨텍스트 파악, 자연스러운 한국어 글쓰기에 탁월한 LLM입니다.
* **주요 용도**: 백엔드 로직 설계, 기술 블로그 초안 작성, 복잡한 비즈니스 로직 리팩토링.

#### 2) [ChatGPT (OpenAI)](https://chatgpt.com)
* **특징**: 웹 검색 연동, 이미지 분석, 데이터 분석(Advanced Data Analysis) 등 다방면에 유용한 표준 AI 도구입니다.
* **주요 용도**: 빠른 기술 검색, 개념 학습, 스크립트 작성 보조.

#### 3) [Google Labs](https://labs.google/)
* **특징**: 구글이 선보이는 가장 앞선 실험적 AI 프로젝트들을 직접 체험할 수 있는 공간입니다.
* **주요 도구**: 문서 기반 인사이트를 추출하는 **NotebookLM**, 음악 생성 **MusicFX**, 이미지 생성 **ImageFX** 등 차세대 생성형 AI 도구 모음.

#### 4) [Google AI](https://ai.google/)
* **특징**: 구글의 공식 인공지능 연구 포털로, 최신 연구 논문, Gemini 모델 업데이트, 책임감 있는 AI 원칙 및 개발자 도구를 종합 제공합니다.
* **주요 용도**: 최신 AI 연구 트렌드 탐색, Gemini API 활용 가이드 확인.

#### 5) [v0 by Vercel](https://v0.dev)
* **특징**: 원하는 화면 UI를 말로 설명하면 React + Tailwind CSS 코드를 실시간으로 빌드해 주는 생성형 UI 도구입니다.
* **주요 용도**: 관리자 대시보드 시안, 모달 팝업, 랜딩 페이지 프로토타이핑.

---

### 2. 개발 · 인프라 & 오픈소스 프로젝트

#### 6) [GitHub](https://github.com)
* **특징**: Git 기반 소스 코드 형상 관리, GitHub Actions를 통한 CI/CD 배포 자동화, GitHub Pages 호스팅 제공.
* **주요 용도**: 개인 프로젝트 백업, 오픈소스 라이브러리 탐색, 블로그 자동 배포.

#### 7) [morluto/rea (GitHub)](https://github.com/morluto/rea)
* **특징**: React 생태계의 다양한 UI 컴포넌트와 유용한 엔지니어링 패턴을 다루는 오픈소스 저장소입니다.
* **주요 용도**: 프론트엔드 모듈 구조 및 컴포넌트 설계 레퍼런스 참고.

#### 8) [Render](https://render.com)
* **특징**: Heroku의 대안으로 떠오른 간편한 PaaS 클라우드로, 웹 서비스, 백엔드 API, 정적 사이트를 원클릭 배포합니다.
* **주요 용도**: Python Flask/FastAPI, Node.js WebSocket 백엔드 서버 무료/저비용 호스팅.

#### 9) [Docusaurus](https://docusaurus.io)
* **특징**: Meta(Facebook)에서 관리하는 오픈소스 문서화 도구로, 마크다운(MDX)만으로 완벽한 정적 위키를 구축합니다.
* **주요 용도**: 현재 운영 중인 `docs.jk-str.com` 지식창고의 핵심 엔진.

---

### 3. UI/UX 디자인 & 시각 평가 도구

#### 10) [bananaX 인포그래픽 평가 (Infographic Evaluation)](https://furoku.github.io/bananaX/projects/infographic-evaluation/ko/?tab=Collage)
* **특징**: AI 및 시각화 알고리즘 기반의 인포그래픽 디자인, 레이아웃 조화도, 콜라주 품질을 비교·평가할 수 있는 프로젝트 페이지입니다.
* **주요 용도**: 시각 자료 배치 연구, 디자인 콜라주 레퍼런스 탐색 및 벤치마킹.

#### 11) [Lucide Icons](https://lucide.dev)
* **특징**: Feather Icons의 후속 오픈소스 프로젝트로, React/Vue 컴포넌트 형태로 즉시 import 가능한 깔끔한 아이콘 모음입니다.
* **주요 용도**: 웹/앱 프로젝트의 버튼, 네비게이션, 상태 배지 아이콘 적용.

#### 12) [Tailwind CSS Docs](https://tailwindcss.com)
* **특징**: 별도 CSS 파일 없이 HTML 태그 안에서 스타일을 완성하는 현대 웹 표준 스타일 가이드입니다.
* **주요 용도**: 반응형 레이아웃 구성, 다크 모드 스타일링, 빠른 CSS 유틸리티 클래스 검색.

### 4. 실무 유틸리티 & 엔지니어링 학습

#### 13) [roadmap.sh](https://roadmap.sh)
* **특징**: 최신 기술 트렌드를 반영한 백엔드, DevOps, 프론트엔드, 시스템 설계 로드맵을 시각적으로 제공합니다.
* **주요 용도**: 기술 스택 확장 시 필수 학습 키워드 점검, CS 지식 체계화.

#### 14) [regex101](https://regex101.com)
* **특징**: Python, JavaScript 등 언어별 정규표현식 동작 결과를 시각적으로 설명하고 매칭 그룹을 즉시 검증합니다.
* **주요 용도**: 결제 내역 문자 파싱, 전화번호/이메일 검증식 테스트, 대량 텍스트 정제.
